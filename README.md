# AgentWriter-AI
# How to run?

1. Clone the repository to your local machine.

```bash
git clone https://github.com/samruddhikullolli/AgentWriter-AI.git
```

2. Navigate to the project directory.
```bash

cd AgentWriter-AI
```

3. create virtual enviornment (optional but recommended)

```bash
conda create -n agentwrite python=3.11 -y
```

4. activate the virtual enviornment .

```bash
conda activate agentwriter
```

5. install the required dependencies.

```bash
pip install -r requirements.txt
```

6. run the application.

```bash
python app.py
```
